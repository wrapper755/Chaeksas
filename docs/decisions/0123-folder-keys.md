# ADR-0123. 연동용·대리 답용 키도 일꾼 폴더의 키 파일로 들인다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-01 |
| 관련 | 계약 C7(§폴더 키·`FolderKey`·`ConsumerFolderScan`), C5(권한표 — 바뀌지 않는다), 화면 CON-07·CON-11, [ADR-0081](0081-answering-on-behalf.md), [ADR-0098](0098-virtual-worker-identity.md), [ADR-0122](0122-consumer-folder.md), `deploy/compose.yaml` |

## 배경

NowView처럼 **Center와 함께 설치되는 연동 시스템**은 일꾼 키 하나와 함께 연동용(`integration`, 작업·메시지·가상 직원)
키와 대리 답용(`relay`, 결재 읽기·답) 키를 쓴다. 일꾼 키는 ADR-0122로 설치 때 해시 파일을 두면 Center가 뜰 때
들이는데, 나머지 둘은 「Center를 띄운 뒤 CON-11에서 발급 → 사람이 연동 시스템 설정에 붙여 넣기」였다. 설치가 끝난
뒤 사람 손이 한 번 더 들어가야 연동이 돈다 — 사용자가 순서가 맞지 않는다고 지적했다(2026-11-01). 범위는 이 두
종류뿐이다(패키지 배포·가상 직원 등록은 하지 않는다).

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. **같은 일꾼 폴더에 `<이름>.key.json`(이름·종류·토큰 해시)** | 일꾼 파일과 한 자리·한 뜻이다. Center는 원문을 모른다 | 파일 꼴이 하나 는다 |
| B. 일꾼 파일에 「이 일꾼의 연동 키」 칸을 더한다 | 파일이 늘지 않는다 | 일꾼과 연동 키는 권한도, 쓰는 프로그램도 다르다 — 한 파일이 둘을 말하면 빼기·바꾸기의 뜻이 엉킨다 |
| C. Center 환경변수에 원문 | 파일이 없다 | Center가 원문을 든다(ADR-0122가 피한 것) |

## 결정

**A.** 일꾼 폴더(`CHK_CENTER__CONSUMERS_DIR`)의 `<이름>.key.json` = C7 `FolderKey{name, type, token_sha256}`.

1. `type`은 `integration`·`relay`만이다 — 다른 종류는 `input_invalid`. 등록 승인이 만드는 키(PC 실행기·Studio·
   서버 실행기)는 이 길로 들이지 않는다(그쪽은 기계에 묶이고 회전한다).
2. **권한은 종류가 정한다** — CON-11에서 발급한 같은 종류의 키와 같다(C5 권한표 그대로). 대리 범위 칸은 두지
   않는다 — 대리 답용 키는 지금도 `X-CHK-On-Behalf-Of`의 그 사람이 담당자인 결재만 받는다(ADR-0081).
3. 뜻은 일꾼 파일과 같다 — Center가 **뜰 때 한 번** 읽고, 해시가 바뀌면 옛 키를 폐기하고 새 키를 만든다.
   **폐기된 토큰은 되살아나지 않고**(`token_revoked`), 다른 키(일꾼 키 포함)가 쓰는 해시는 거절한다(`token_in_use`).
   **파일이 빠지면 폐기한다**(행은 남아 CON-11에 「폐기됨」으로 보인다). 읽지 못한 파일은 자리를 지킨다.
4. 키의 자리는 파일 이름(확장자 앞)이고 `center_keys.folder_file`(21판)에 적는다. 앞자리(`prefix`)는 비어 있다 —
   원문을 모르니 해시로만 찾는다(`keys.find`, 일꾼 키와 같다). 만료·회전이 없다.
5. 토큰 원문의 권장 꼴은 Center API 키와 같다(`chk_ctr_` + `[A-Za-z0-9_-]` 40자) — Center는 해시만 맞춘다.
   `chk-center key-file <이름> --type integration|relay [--dir 폴더]`가 파일을 짓고 원문을 한 번 찍는다.
6. 결과는 `ConsumerFolderScan.items[]`의 `kind: key` 줄로 로그·`GET /resources/consumer-folder`·CON-07
   「일꾼 폴더」에 보인다. 콘솔에서 발급한 같은 종류의 키와 함께 있어도 된다.

## 결과

- 함께 설치되는 연동 시스템은 설치 때 세 파일(일꾼·연동용·대리 답용)을 두면 Center가 뜨는 순간부터 돈다.
- CON-11에는 폴더 키가 「연동 키」 표에 보이고 앞자리는 「—」다. 폐기는 CON-11에서도 할 수 있다 — 그러면 다음에
  뜰 때 그 파일은 `token_revoked`로 거절된다(새 토큰으로 바꾼다).
- 알려진 틈: CON-11 「삭제」로 폐기된 행을 지우면 Center가 그 해시를 잊어 같은 파일이 다시 들어온다. 일꾼 키와
  같다 — 폐기를 원하면 파일도 뺀다.
