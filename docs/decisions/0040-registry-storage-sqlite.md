# ADR-0040. UI 자동화 레지스트리는 SQLite 한 파일에 둔다 (그래프 저장소를 두지 않는다)

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-10-09 |
| 관련 | [C9](../03-contracts/C9-ui-page-registry.md), [C8](../03-contracts/C8-ui-automation-plan-heal-report.md), [09-gaps](../09-gaps.md) §2-3·§4-7, 화면 UIA-01·02, [ADR-0010](0010-service-apps.md) |

## 배경

UI 자동화 앱의 화면 레지스트리는 **이미 SQLite 한 파일**로 돈다 (`service/store.py` — 표준
라이브러리 `sqlite3`만 쓴다). 그런데 문서 네 곳은 아직 **지식 그래프(Neo4j)**를 전제한다:
`01-architecture.md`(저장소 표), `04-setup.md`(Docker로 Neo4j를 띄우는 절차와 포트 표),
C9(§오류 `registry_unavailable` 「그래프 저장소(Neo4j)가 내려감」, §호환 규칙), 그리고
`06-screens/service-app-console.md`의 UIA-01 「저장소 표시」·UIA-02 「통계 열은 그래프
저장소에서만 채워집니다」.

그래프는 프로토타입(UI 자동화 서버)에서 왔고, **그 뒤집기를 적은 ADR이 없다.** 결정이 적혀
있지 않으니 화면을 만들 때마다 「그래서 지금 저장소가 뭔가」를 다시 묻게 되고, UIA 화면 셋이
그 질문에 걸려 멈춰 있다 (09-gaps §4-7). 지금 정해야 하는 이유는 그것이다 — 코드를 바꾸려는
것이 아니라 **이미 간 길을 적어 막힌 화면을 풀려는 것**이다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. SQLite 한 파일 (지금 구현) | 서비스 앱 하나에 **설치할 것이 없다** — 파일 하나라 백업·복제가 복사다. 표준 라이브러리라 의존이 늘지 않는다. 승격·통계는 행 몇 개를 세는 일이라 관계형이 더 곧다 | 「화면 간 경로 탐색」을 질의 한 줄로 못 한다 — 앱 코드가 걸어야 한다. 화면·요소가 **수만**이 되면 전체 훑기가 느려진다 |
| B. Neo4j로 되돌린다 | 경로 탐색·이웃 질의가 질의 한 줄. 프로토타입 경험이 그대로 쓰인다 | 서버에 **DB 하나를 더** 세운다(컨테이너·비밀번호·백업). 서비스 앱 하나가 무거워져 `docker compose` 한 번으로 뜨는 지금 구성이 깨진다. 드라이버 의존이 늘고, 개발 PC마다 Neo4j를 띄워야 시험이 돈다 |
| C. 둘 다 (그래프 + 파일 폴백) | 작은 설치는 가볍고 큰 설치는 빠르다 | **코드가 두 벌**이 된다 — 프로토타입에서 YAML 폴백이 그랬고, 두 길의 동작이 갈라져 레지스트리 버그를 재현할 수 없었다. 화면도 「어느 저장소냐」를 보여야 한다 |

## 결정

**A — SQLite 한 파일로 간다.** 그래프 저장소를 두지 않고, 폴백도 두지 않는다.

- **저장소는 계약에 드러나지 않는다.** C9 응답에 `backend`·`path` 같은 칸을 두지 않는다 (이미
  그렇다). 저장소를 바꾸는 것은 그 앱의 속사정이다.
- **화면에서 「저장소 표시」를 뺀다.** 고를 것이 없으면 보일 것도 없다 — 하나뿐인 것을 적어
  두면 「다른 것도 있나」로 읽힌다. UIA-01은 그 줄 없이 그린다.
- **통계 열은 늘 있다.** 「그래프 저장소에서만 채워집니다」는 지운다 — `LocatorStats`가 성공·
  실패·연속 성공을 들고 있고, 승격(연속 3회)도 그것으로 돈다 (C8).
- **「화면 간 경로 탐색」은 앱 코드가 건다.** 간선은 요소의 「이동하는 화면」(C9
  `navigates_to`)이고, 출발→도착 최단 경로를 **너비 우선으로** 찾는다. 화면 수가 수백인
  규모에서 메모리로 도는 일이라 질의 언어가 필요하지 않다. 재귀 CTE로 SQL에 밀어 넣지 않는다 —
  읽기 어렵고 시험하기 어렵다.
- `registry_unavailable`(503)의 뜻은 **「저장소가 내려감」**으로 남긴다 — 무엇이 저장소인지는
  적지 않는다.

## 결과

- 이 결정으로 쉬워지는 것: UIA-01·02·03을 **지금 만들 수 있다** (09-gaps §4-7의 막는 것이
  풀린다). 서버 구성이 `deploy/compose.yaml` 하나로 남는다. 개발 PC에 Docker 없이 시험이 돈다.
- 어려워지거나 포기하는 것: 그래프 질의로 할 수 있던 것(임의 깊이의 이웃 탐색, 「이 요소를
  거치는 모든 경로」)은 앱 코드로 짜야 한다. 지금 화면이 요구하는 것은 최단 경로 하나뿐이다.
- 다시 볼 조건: 한 설치의 **화면이 수천**을 넘어 전체 훑기가 눈에 띄게 느려지거나, 경로 탐색이
  「최단 하나」를 넘어 **여러 경로·가중치**를 요구할 때. 그때도 먼저 보는 것은 Neo4j가 아니라
  **SQLite 인덱스와 질의**다 (파일 하나를 포기하는 값이 크다).
