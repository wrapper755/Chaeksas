# ADR-0076. Admin 창(ADM-01~03)은 짓지 않는다 — 서명은 명령 한 번에 키를 열고 닫는 CLI에 남는다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-10-18 |
| 관련 | 화면 `admin.md`(ADM-01~03 「창 초안」), C2 서명 봉투, `apps/admin`(`chk-admin`), [ADR-0013](0013-api-keys.md), [ADR-0053](0053-no-watch-mode-in-studio.md), 05-roadmap 「나중에」, 09-gaps §7-8 |

## 배경

`admin.md`는 첫 릴리스를 **명령줄만**으로 정하고, 키 관리·승인 대기·배포를 창으로 하는 ADM-01~03을 「창 초안 (나중)」으로 적어 두었다. 로드맵도 「Admin 데스크톱 창」을 **「나중에 (범위 밖)」**에 두었다. 09-gaps §7-8은 그 초안을 화면 문서의 「아직」으로 모으며 먼저 정할 것을 이렇게 적었다 — 지금은 `chk-admin`이 다 하고, 창은 **개인키를 다루는 화면이라 CLI보다 넓은 공격면**이 된다.

`chk-admin`이 지금 하는 것을 보면:

- 키 만들기·목록·Center 등록·철회, 승인 대기 목록, 승인·배포·철회 서명, 외부 확장 서명·철회, 지원 종료, 작업 만들기·목록·취소가 돈다. **하나가 빠져 있었다** — 명령 표의 `deploy … --server [--max-concurrency]`(서버 배포 서명)인데 `deploy`가 `--bot-ui`를 필수로 받아 **사람이 서버 Bot을 배포할 길이 없었다**(계약·Center·실행기는 다 받고 시험은 봉투를 코드로 지었다). 이 결정과 함께 메웠다 — 그래서 이제 ADM-01~03이 할 일 중 CLI가 못 하는 것이 없다.
- **개인키는 명령 한 번 동안만 열린다** — 암호를 묻고(`getpass`, 빈 암호는 받지 않는다) 서명하고 프로세스가 끝난다. 확인 문구(해시·대상·유효 기간·「무효가 됩니다」)는 서명 **전에** 보인다.
- 「읽기」는 서명이 필요 없다 — 승인 대기·배포·작업 목록은 Center 콘솔(CON-02·CON-03·CON-05·CON-06)이 이미 보여 준다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. ADM-01~03을 PySide6 창으로 짓는다 | 명령을 외우지 않는다. 고르기(Bot UI·버전)가 쉽다 | **오래 떠 있는 프로세스**가 암호나 열린 키를 쥐게 된다(누를 때마다 묻지 않으면). Admin PC에 Qt(·WebEngine)를 들인다 — 서명 PC의 소프트웨어가 커질수록 믿을 것이 늘어난다. CLI와 **같은 일을 하는 길이 둘**이 되고 확인 문구가 갈라질 수 있다 |
| B. 서명을 웹(콘솔)으로 옮긴다 | 어디서나 된다 | **서명이 서버에서 일어나지 않는다**는 관문 자체를 버린다(C2 — 토큰이 새도 배포를 못 하게 하는 마지막 관문) |
| C. **짓지 않는다** — CLI가 유일한 서명 길로 남고, 창 초안은 다시 볼 조건과 함께 둔다 | 키가 열리는 시간이 가장 짧다. 서명하는 코드가 한 벌이다. 읽기는 콘솔이 이미 한다 | 명령을 쳐야 한다 — 고르는 일(배포 대상 Bot UI id 등)은 콘솔에서 읽어 와 붙여 넣는다 |

## 결정

**C로 한다.** Admin 창은 지금 짓지 않는다.

1. **서명하는 길은 `chk-admin` 하나다.** 개인키는 명령 한 번 동안만 열리고 프로세스와 함께 닫힌다.
2. **읽는 일은 Center 콘솔이 한다** — 승인 대기(CON-06)·배포(CON-03)·작업(CON-05). Admin이 서명에 필요한 id(배포 대상 Bot UI·배포 id)는 거기서 읽는다.
3. `admin.md`의 「창 초안」은 **지우지 않고** 이 ADR을 가리키는 상태 줄을 단다 — 다시 볼 때 출발점이다. 09-gaps §7-8은 닫는다(로드맵 「나중에」에 남는다).

## 결과

- 쉬워지는 것: 서명 PC에 들일 것이 늘지 않는다. 확인 문구와 서명 코드가 한 자리에 있다.
- 어려워지거나 포기하는 것: Admin이 명령줄을 쓴다. 여러 건을 한꺼번에 승인·배포하는 일은 명령을 되풀이한다.
- 다시 볼 조건: ① Admin이 명령줄을 쓰지 않는 사람으로 바뀌어 **서명이 미뤄지는 일**이 생기면(승인 대기가 쌓인다). 그때도 창은 **누를 때마다 암호를 묻고 서명 뒤 키를 버리는** 모양이어야 하고, 확인 문구는 CLI와 **같은 함수**에서 와야 한다. ② 서명을 하드웨어 키(스마트카드·보안 키)로 옮기게 되면 — 그때는 키가 PC 메모리에 열리지 않으므로 공격면 셈이 달라진다.
