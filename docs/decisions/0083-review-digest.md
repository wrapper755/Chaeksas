# ADR-0083. 결재의 검토 자료는 **다이제스트로 고정**하고, 답하는 쪽이 본 것과 다르면 받지 않는다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-10-20 |
| 관련 | [ADR-0079](0079-virtual-worker-is-an-intake-bot.md)(일괄 결재), [ADR-0081](0081-answering-on-behalf.md)(대리 답), [C6](../03-contracts/C6-approvals.md), 바깥 요청서 W5 |

## 배경

일괄 결재(ADR-0079)에서 감독자는 N건을 **한 번** 보고 승인한다. 대화 창구는 결재를 읽어 카드로 보이고, 감독자가 누르면 대리 답(ADR-0081)으로 나른다. 카드를 만든 때와 답을 나르는 때 사이에 **결재가 다른 것으로 바뀌지 않았다**는 것을 답하는 쪽이 확인할 길이 있어야 한다.

C6은 이미 같은 `request_id`에 다른 본문을 받지 않는다(409 `idempotency_conflict`). 그래서 **결재 하나의 `review`는 올라온 뒤 바뀌지 않는다.** 남는 틈은 둘이다 — 답하는 쪽이 **다른 결재**를 같은 것으로 착각하는 일(id를 잘못 들고 있다), 그리고 값을 30일 뒤 지운 뒤에는 「무엇을 승인했나」를 맞춰 볼 근거가 없는 일이다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. 아무것도 더하지 않는다 — `request_id`가 이미 본문을 고정한다 | 할 일이 없다 | 답하는 쪽이 본 것을 Center가 대조하지 못한다. 값을 지운 뒤 감사 근거가 없다 |
| **B. Center가 `review_digest`를 계산해 두고, 답에 `if_review_digest?`를 받는다** | HTTP `If-Match`와 같은 결이라 익숙하다. 값을 지워도 다이제스트는 남는다(업무 값이 아니다). 선택 칸이라 콘솔은 그대로다 | 정규화 규칙을 양쪽이 같게 지켜야 한다 |
| C. 답하는 쪽이 `review` 전체를 다시 보낸다 | 다이제스트 규칙이 필요 없다 | 업무 값이 한 번 더 오간다 (원칙 6의 예외를 넓힌다) |

## 결정

**B.** C6에 둘을 더한다.

- **`ApprovalInfo.review_digest`** — Center가 결재를 받을 때 계산해 저장한다. 규칙은 `sha256:` + **정규화한 `review`의 SHA-256**(16진 소문자)이고, 정규화는 키 정렬·구분자 `,`/`:`·UTF-8·한글 그대로(`json.dumps(review, sort_keys=True, separators=(",", ":"), ensure_ascii=False)`)다. 함수는 `contracts.approvals.review_digest` 하나이고 받는 쪽과 연동하는 쪽이 같은 규칙을 쓴다. `review`가 비어도 다이제스트는 있다(`{}`의 것). **값을 지운 뒤에도 남긴다** — 업무 값이 아니라 그 값의 지문이다.
- **`AnswerRequest.if_review_digest?`** — 있으면 지금 결재의 다이제스트와 맞아야 한다. 다르면 **409 `review_changed`**이고 답을 받지 않는다. 없으면 지금과 같다(콘솔은 싣지 않는다).
- 이 칸이 생기기 전에 올라온 결재는 다이제스트가 없다. 그때는 남아 있는 `review`로 **읽을 때** 계산하고, 값도 지워졌으면 비어 있다 — 그 결재에 `if_review_digest`를 실어 답하면 맞춰 볼 근거가 없으므로 `review_changed`다.

## 결과

- 이 결정으로 쉬워지는 것: 대화 창구가 카드에 다이제스트를 실어 「보여 준 것 = 승인하는 것」을 Center에서 한 번 더 확인한다. 30일 뒤에도 「무엇에 승인했나」를 지문으로 맞춰 볼 수 있다.
- 어려워지거나 포기하는 것: 정규화 규칙이 계약이 된다 — 바꾸려면 판을 올려야 한다. 수의 표기(`1.0` ↔ `1`)는 JSON이 준 그대로라, 연동하는 쪽은 **Center가 준 다이제스트를 그대로 되돌려 보내야** 한다(제 손으로 다시 계산하지 않는다).
- 다시 볼 조건: 연동하는 쪽이 다이제스트를 제 손으로 계산해야 하는 일이 생기면 — 그때 수 표기 규칙까지 정한다.
