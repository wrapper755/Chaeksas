# ADR-0011. 포트는 기본값 + 설정 변경, 환경변수 접두사는 CHK_

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-10-01 |
| 관련 | `docs/04-setup.md` §5·§6 |

## 배경

프로토타입은 포트를 코드 곳곳에 고정했고, 환경변수 접두사가 구성요소마다 달랐다(세 가지). 새 저장소는 서버(Linux)와 클라이언트(Windows)가 다른 PC에 있고, 서비스 앱이 계속 늘어난다.

## 결정

- **포트:** 구성요소마다 기본 포트를 정하고, 설정 파일 또는 환경변수로 바꿀 수 있게 한다. 코드에 포트 숫자를 직접 쓰지 않고 설정 모델의 기본값에만 둔다. 기본값은 `docs/04-setup.md` §6의 표가 원본이다.
- **환경변수 접두사:** `CHK_` 하나. 구성요소·항목은 `__`로 중첩한다 (`CHK_CENTER__PORT`, `CHK_WORKER__LOCAL_API__PORT`).
- **우선순위:** 환경변수 > `.env` > 설정 파일 > 기본값.
- **바인드:** Worker 로컬 API는 포트만 바꿀 수 있고, 주소는 127.0.0.1로 고정한다.

## 결과

- 쉬워지는 것: 같은 PC에서 여러 구성요소를 띄울 때 충돌을 설정으로 해결. 서비스 앱 추가 시 규칙이 이미 있음.
- 어려워지는 것: 모든 구성요소가 같은 설정 로더를 써야 한다 (`packages/core` 또는 `service_kit`에 공통 구현).
- 다시 볼 조건: 없음.
