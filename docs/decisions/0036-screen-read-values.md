# ADR-0036. 화면에서 읽은 값의 모양 — 표는 머리글을 열쇠로 하는 줄 목록, 수 모양 글은 수

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-10-05 |
| 관련 | [ADR-0025](0025-expression-language.md)(도우미 `합계`·`표를사전`), [ADR-0033](0033-desktop-app-and-window.md), 계약 C10·C14, 인수 시험 BX-04 |

## 배경

C10은 `read_table`의 `data`에 `headers`·`rows`가 실린다고 적었지만 아무도 싣지 않았다. 수행기는 `text`(TSV 글 하나)만 변수에 넣었다. 그래서 BX-04가 막혔다.

- **표.** `건수 = len(거래내역)`은 줄 수가 아니라 글자 수가 된다. `합계(거래내역, '금액')`은 「목록이어야 한다」로 실패한다. 도우미(`합계`·`표를사전`·`묶기`)는 처음부터 **사전 목록**을 받도록 만들어져 있다 (ADR-0025).
- **수.** 회계 시트의 합계 칸을 읽으면 `"251"`(글)이다. 포털 합계는 `251`(수)이다. `시트합계 == 포털합계`가 늘 거짓이다.

예제를 비틀지 않고(CLAUDE.md §3-6) 계약에 적는다.

## 선택지

표의 값.

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. TSV 글 그대로, 스크립트가 쪼갠다 | 바꿀 것이 없다 | 모든 BPM 프로세스가 같은 쪼개기를 쓴다. 칸 안의 탭·줄바꿈에서 깨진다 |
| B. **머리글을 열쇠로 하는 사전 목록** | 도우미가 그대로 맞는다. 열 이름으로 읽힌다 | 머리글 없는 표·겹치는 머리글의 규칙이 필요하다 |

수.

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| C. 늘 글. 스크립트가 `int()` | 놀랄 일이 없다 | `int("1,200,000")`이 실패한다. 예제마다 바꾸기 줄이 붙는다 |
| D. 스텝마다 타입을 적는다 (`as: number`) | 분명하다 | 예제·편집기·계약이 모두 바뀐다. 표의 칸마다는 적을 수 없다 |
| E. **수 모양이면 수**로 읽는다 (좁은 규칙) | 예제가 그대로 돈다. 표와 `read`가 같은 규칙이다 | 수처럼 생긴 번호가 수가 된다 — 규칙을 좁혀 막는다 |

## 결정

**B + E.**

1. **`read_table`의 결과 변수는 줄 목록이다.** 한 줄은 `{머리글: 값}` 사전이다.
   - 첫 줄이 머리글이다.
   - 빈 머리글은 `열1`·`열2`…(자리 번호), 겹치는 머리글은 뒤에 `_2`·`_3`을 붙인다.
   - 칸이 모자란 줄은 빈 글로 채우고, 남는 칸은 버린다.
   - Worker는 C10 `data`에 `{headers, rows}`(글 그대로)를 싣는다. 사전으로 바꾸는 일과 수 규칙은 **수행기**가 한다 (부르는 쪽마다 같은 함수). `text`(TSV)는 사람이 읽는 형태로 그대로 둔다.
2. **수 규칙.** 앞뒤 공백을 뺀 글이 다음 모양일 때만 수다. 그 밖은 글 그대로다.
   - 부호(`-`)가 있을 수 있다.
   - 정수부는 `0`이거나 0으로 시작하지 않는 숫자다. 세 자리마다 쉼표가 있어도 된다.
   - 소수부가 있을 수 있다.
   - 소수부가 있으면 `float`, 없으면 `int`다. 쉼표는 지운다.

   예: `"1,200,000"` → `1200000`, `"-3.5"` → `-3.5`.
   글로 남는 예: `"007"`(앞의 0), `"02-1234-5678"`, `"1.2.3"`, `"12%"`, `"₩1,000"`, `"1,23"`(쉼표 자리가 틀림).
3. **같은 규칙을 `read`에도 쓴다.** 표의 칸과 칸 하나 읽기가 다르면 같은 값이 두 모양이 된다. `read_options`·`read_selection`은 글 그대로다 (고를 거리의 이름이다).
4. 수가 된 값을 다시 스텝 값(`{이름}`)으로 넣으면 쉼표 없는 숫자 글이 된다.

## 결과

- 쉬워지는 것: `len`·`합계`·`표를사전`이 화면에서 읽은 표에 그대로 맞는다. 합계 비교가 수끼리 된다. BX-04가 예제 그대로 돈다.
- 어려워지는 것: 0으로 시작하지 않는 번호(`1001`)는 수가 된다. 글로 다뤄야 하면 스크립트에서 `str()`을 쓴다. AI 태스크에 가는 표가 TSV 글이 아니라 사전 목록(JSON)이 된다 (BX-14).
- 다시 볼 조건: 수 규칙 때문에 틀린 업무가 나오면 D(스텝마다 타입)를 더한다. 머리글이 두 줄인 표가 잦으면 머리글 줄 수를 화면 등록(C9)에 둔다.
